155,422 bp (Circular)

# Source of the genome file

NCBI Nucleotide (RefSeq). The annotated GenBank file was downloaded as *Dracaena_draco*_NC_048492.1.gb and kept unchanged in the data folder.

# Software used:

OGDRAW (OrganellarGenomeDRAW) version 1.3.1, CHLOROBOX, Max Planck Institute of Molecular Plant Physiology.

# OGDRAW settings

I used Standard mode and uploaded the GenBank file. The map type was Circular and the sequence source was Plastid. Inverted repeats were detected automatically. I turned on the GC content graph, direction of transcription, full legend, and asterisk labels for intron-containing genes. The output format was PNG at fine resolution.

# Main structural features

The plastid genome has a circular structure consisting of one large single-copy (LSC) region, one small single-copy (SSC) region, and two inverted repeat regions (IRa and IRb). The map also shows genes distributed around the genome in both directions, with the two IR regions containing duplicated genetic information.
